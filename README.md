# Reactix Raw — one-knob tech-house riser

![Reactix Raw](https://raw.githubusercontent.com/RemiBlaze/ReactixRaw/main/reactixraw-ui-screenshot.png)

**Build a tech-house riser into the drop with a single knob.**

Reactix Raw is the free, one-knob version of **Reactix**. Turn up the **REACTOR** knob and reverb, ping-pong delay, saturation, and a high-pass sweep rise together into a full transition — then snap clean when you pull it back to zero.

Fully **signed and notarized** for macOS as **AU, VST3, and Standalone**.

---

## 🚀 Download & Install
1. Go to the [latest release](https://github.com/RemiBlaze/ReactixRaw/releases/latest).
2. Download **`ReactixRaw_Installer.pkg`**.
3. Double-click it and follow the installer. Signed & notarized by Apple — installs cleanly, no security warnings.
4. Restart your DAW and rescan plug-ins.

Full guide: **[remiblaze.com/support](https://remiblaze.com/support/)**.

---

## 🎛️ What It Does
One big **REACTOR** knob drives the whole engine. As you turn it up from 0% to 100%, a reverb tail, a ping-pong delay, saturation, and a high-pass filter sweep come in on front-loaded curves and build together into a riser. The build is level-matched, so it grows more energetic without jumping in volume. Pull the knob back to 0% for an instant clean reset.

Drop it on a loop or a breakdown, ride the knob into the drop, and release to reset. That single automatable knob is the entire plug-in — nothing else to dial in.
